# devops-capstone-project

![Build Status](https://github.com/OminduD/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)

This repository contains the customer accounts microservice for the e-commerce capstone project. The service is built with Python and Flask, utilizing a RESTful API to manage customer profile data (names and addresses). 

## Features Planned
- Account CRUD operations (Create, Read, Update, Delete)
- List customer accounts
- Docker containerization
- Kubernetes orchestration
